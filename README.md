Nova Horizon University is a practice project designed to improve front-end development skills using HTML, CSS, and JavaScript. The website focuses on modern UI design, responsive layouts, and smooth user interaction.

The project includes:

Transparent navigation bar

Hero section with background image overlay

Programs section with horizontal cards

Campus information section

About Us section

Styled footer

Scroll-based navbar effects

Responsive design structure

🚀 Features

Modern landing page layout

Responsive navigation bar

Transparent-to-solid navbar transition on scroll

Background image overlay effects

Program cards with student images

Smooth scrolling navigation

Clean typography and spacing

Responsive footer section

🛠️ Built With

HTML5

CSS3

JavaScript

📂 Sections Included

Home

A hero section introducing the university with a modern background image and call-to-action buttons.

Programs

Displays featured academic programs using styled cards and images.

Campus

About Us

Provides information about the university’s mission and vision.

Footer
